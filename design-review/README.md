# MVP Realty — Design Review

Coastal "Gulf of Mexico" visual system (aqua seafoam + deep ocean blue) for the MVP Realty
website. These are clickable HTML mockups for review — **open `index.html` in any browser** to
launch the gallery with live previews of every direction and page.

> Property photos are stock imagery for vibe only; the real site pulls listings from the MLS/IDX
> feed. If an image can't load (e.g. offline), it falls back to a coastal gradient so nothing looks
> broken.

## How to view

Double-click **`index.html`** — no install, no internet required for the layouts (only the stock
photos need a connection).

## What's inside

### Home-page directions (`home/`)

Fifteen takes on the homepage, all on the same coastal palette. Directions **J–O** are tuned for the **55+ retiree buyer** and each adds two features the others don't: **featured listings on the homepage** and a dedicated **amenities** module. Every page is live-adjustable via its floating Tweaks panel.

- **I3 — Coastal Noir** — restrained dark take on the GL Homes brief. One locked dark-ocean theme, near-monochrome, sharp edges; seafoam survives only as a 1px hairline and on the numerals. Communities read as a clean divided index.

#### 55+ explorations (J–O) — _new; each with homepage listings + amenities_

- **J — Sunlit Friendly** — warmest, most approachable. Cream/sand surfaces, big pillowy rounded cards, true sun-gold accent, friendly Lora serif sized up for older eyes.
- **K — Coastal Botanical** — nature- and wellness-led. Sage + seafoam + sand, organic radii, tidal reveals; trails, mangrove preserves, and sunrise yoga alongside resort amenities.
- **L — Elegant Concierge** — white-glove luxury. Playfair Display serif over deep navy + ivory, gold rationed to accents/hairlines, concierge-voiced copy, slow restrained motion.
- **M — Cool Smooth Modern** — cool, glassy, frictionless. Airy blue gradients, smooth medium-large radii, frosted surfaces, gentle hero parallax; high-contrast for legibility.
- **N — Bold Reassurance** — accessibility-first and trust-led. Deep ocean blue, extra-large type, oversized buttons, trust/review module, plus a live text-size control.
- **O — Serene Retreat** — calmest. Light Cormorant serif, pillowy/very-rounded forms, pale mist-and-seafoam surfaces, slow breathing motion and generous whitespace.

- **A — Tranquil Editorial** — airy, full-bleed ocean hero, floating search, magazine grid
- **B — Bold Confident** — split-screen, oversized headlines, gold accent rhythm
- **C — Boutique Warm** — soft sand tones, agent-forward, prominent testimonials
- **D — Sleek Modern Luxury** — dark navy, glassy search, seafoam glow, gallery wall
- **E — Portal / Search-First** — map + live results (closest to the inspiration sites, elevated)
- **F — Lifestyle Magazine** — full-bleed storytelling, editorial blocks
- **G — Refined Minimal** — centered, airy, restrained luxury
- **H — Coastal Vibrant** — seafoam-forward, rounded, energetic

### Core site pages (`pages/`)

- **listings.html** — Property listings (PLP): filters, sort, results grid + map
- **property.html** — Property detail (PDP): gallery, key facts, floor plan, map, lead form
- **agents.html** — Agents: team grid + featured broker profile + testimonials

### Shared assets (`assets/`)

- **tokens.css** — the color palette, type, spacing, and shared components
- **site.css** — shared header / footer / card styling for the core pages

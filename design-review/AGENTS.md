# Design review agent instructions

Root rules in `/AGENTS.md` apply. This directory holds static design review artifacts and mockups.

## Hard rules

- Treat these files as reference and evaluation material, not production runtime code.
- Do not migrate tweak-panel or mockup tooling into the app without an explicit decision.
- Ground design critique against current `apps/web` implementation and `docs/design-port-decisions.md`.
- Property photos here are vibe/reference material until replaced by owned assets or Payload Media.
